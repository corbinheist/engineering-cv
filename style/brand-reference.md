# Echodyne 2024 Brand Guidelines — PDF Style Reference

Quick reference for the brand elements applied in `style/template.tex`.
Source: Echodyne 2024 Brand Guide (internal).

## Typography

| Weight | Font | Use |
|--------|------|-----|
| Light (45) | Helvetica Neue Light | Name header |
| Roman (55) | Helvetica Neue | Body text |
| Bold (75) | Helvetica Neue Bold | Section headings, inline bold headers |
| Italic (56) | Helvetica Neue Italic | Skills lines, emphasis |

**CI fallback**: TeX Gyre Heros (metric-compatible Helvetica clone) or Arial (brand-approved alternate, p.11).

## Colors

| Name | Hex | Usage |
|------|-----|-------|
| Sapphire 300c | `#005cb9` | Section headings, horizontal rules, links |
| Black | `#000000` | Body text |
| White | `#ffffff` | Background |
| Black 60 | `#646b6e` | Secondary text (dates, contact info, footer) |
| Ceramic | `#e9e8e6` | Reserved for future accent use |

## Design Principles

- Clean, minimal, bold
- Sapphire Blue as accent only — not dominant
- Horizontal rules as section separators
- Generous whitespace
- Booktabs-style tables (thin top/bottom rules, no vertical rules)
